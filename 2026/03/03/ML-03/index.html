这种叫：
One-Hot Encoding（独热编码）把一个类别变量变成一个只有0和1的向量。

规则：

  • 这个类别所在位置 = 1

  • 其他类别位置 = 0

例子1：水果类别
假设有三种水果：
Apple
Banana
Orange
给每个类别一个位置：
Apple → [1,0,0]
Banana → [0,1,0]
Orange → [0,0,1]
特点：

  • 只有 一个1

  • 其他都是 0
