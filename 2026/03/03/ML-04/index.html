深度学习笔记（四）：数学角度看机器学习

batch 是训练时的数据组织方式，即投喂的样本数，也就是数据的第一个维度。
embedding 是一种 表示方法（representation）。
本质：离散ID → 连续向量
attention 是一种 计算机制（operation / layer）。
它的功能：
计算序列元素之间的依赖关系
核心公式：
Attention(Q,K,V)=softmax(QKT)
所以 attention 是：一种矩阵计算操作
几乎所有 Transformer 代码都是：
(batch, seq_len, hidden_dim)
以及为什么 Multi-head attention 会变成 4维张量：
(batch, heads, seq_len, head_dim)

一、自动微分核心知识点

1 自动微分的目的

在机器学习中，我们需要优化参数：loss(w)
为了更新参数，需要计算：d lossdw
自动微分的作用：自动计算梯度

2 requires_gradD

代码：
x = torch.arange(4.0)
x.requires_grad_(True)
含义：告诉框架 ，x需要计算梯度，否则不会记录计算过程。

3 计算图（computation graph）

当你写：y = 2 * torch.dot(x, x)
框架会记录：x → dot → multiply → y
这就是：计算图。每个节点是一个计算操作。

4 backward()

代码：y.backward()
含义：从 y 开始 反向计算梯度
得到：x.grad

5 梯度存在哪里

每个变量都有：x.grad
里面存：dydx\frac{dy}{dx}dxdy​

6 梯度累加

如果多次计算：loss.backward()
梯度会累加
所以训练时通常要：optimizer.zero_grad()

7 向量的 backward

如果y 是向量
框架默认：先 sum 再求导
因为训练目标必须是：
标量 loss

8 detach

代码：u = y.detach()
作用：切断计算图
之后梯度不会继续传播。

二、计算图

定义

一句话：计算图 = 记录计算步骤
例如：y = 2 * x * x计算过程是：
x → square → multiply → y
画出来：

这就是：一张有向图

为什么要有计算图

因为要算导数。
例如：y=2x2
你手算：dydx=4x
但神经网络不是这么简单。
例如：y=sin(Wx+b)
可能有：几百万个参数
手算导数不可能。
所以框架必须：记录所有计算步骤
这就是：计算图

三、反向传播

到底在干嘛

核心一句话：用链式法则算导数
回忆微积分：如果：z=f(y)y=g(x)，那么：dzdx=dzdydydx
这就是：链式法则

为什么要“反向”传播

假设：y = 2(x+3)^2
计算步骤：x → +3 → square → ×2 → y
正向计算：x → y。但求导：从 y 往回算
因为：dydx=dydududx，所以必须：从结果往回算
这就是：反向传播

四、线性回归

1. 回归问题与线性模型

  • 回归问题：目标是预测连续数值（如预测房价、股票价格、气温）。与之相对的是预测离散类别的“分类”问题（如识别猫或狗）。
  • 线性假设：假设目标值（输出）可以由特征（输入）的加权和加上一个偏置量来表示。
    • 公式：
    • 权重（Weight, w）**：决定每个输入特征的重要程度。
    • 偏置（Bias, b）：当所有特征都为0时，预测的基础值。

2. 损失函数 (Loss Function)

  • 作用：衡量模型当前的预测值和真实标签之间的差距。
  • 平方损失（Squared Error）：线性回归中最常用的损失函数。
    • 单样本公式：l(i)=0.5*(y^(i)−y(i))^2
      （乘以 0.5是为了求导时能与平方项的^2抵消，方便数学计算）。
  • 目标：寻找一组最优的参数w和b，使得整个训练集上的总损失最小。
  • 泛化：更难做到的是找到一组参数，这组参数能够在我们从未见过的数据上实现较低的损失， 这一挑战被称为_泛化_

3. 优化算法

  • 解析解（Analytic Solution）：线性回归非常简单，是少有的可以直接通过数学公式（矩阵求导）一步算出全局最优解的模型。公式为：
  • 小批量随机梯度下降（Minibatch Stochastic Gradient Descent, SGD）：这是深度学习中真正使用的普适方法。因为复杂的深度模型没有解析解，必须通过这种“一步步试错改进”的算法来逼近最优解。
    • 步骤：随机抽取一小批数据计算误差对参数的导数（梯度），顺着梯度的反方向稍微更新一下参数。
    • 超参数：批量大小（Batch Size）和学习率（Learning Rate）。这些是人为设定的，而不是模型自己学到的。

4. 矢量化加速 (Vectorization)

  • 核心准则：在深度学习代码中，计算多个样本的预测值和损失时，千万不要用 for 循环。
  • 原因：应该利用线性代数，将数据打包成矩阵和向量进行计算。底层硬件（特别是 GPU）对矩阵运算有极强的并行处理能力，速度比 for 循环快成百上千倍。

5. 理论支撑：正态分布与最大似然估计

  • 为什么一定要用平方损失？ 这一节给出了统计学解释。
  • 假设：真实值y等于模型的完美预测值加上一些无法控制的随机噪声
  • 如果假设这些噪声服从正态分布（高斯分布），那么根据统计学中的“最大似然估计（MLE）”原理，要让当前数据出现的概率最大，数学推导出的结果完全等价于最小化均方误差。

6. 从线性回归到深度网络

  • 网络结构：线性回归可以被看作是一个最简单的单层神经网络。

  • 全连接层：在这个网络中，输入层的所有特征节点都通过带权重的连线，直接连接到输出层的唯一一个神经元上。这种所有节点完全相连的结构，就是深度学习中最基础的“全连接层”。

    如上所示的神经网络中，输入为x1—-xd， 因此输入层中的输入数（或称为特征维度）为d。 网络的输出为o1，因此输出层中的输出数是1。 需要注意的是，输入值都是已经给定的，并且只有一个计算神经元。 由于模型重点在发生计算的地方，所以通常我们在计算层数时不考虑输入层。 也就是说，图中神经网络的_层数_为1。 我们可以将线性回归模型视为仅由单个人工神经元组成的神经网络，或称为单层神经网络。
    对于线性回归，每个输入都与每个输出（在本例中只有一个输出）相连， 我们将这种变换（ 图中的输出层） 称为全连接层或称为稠密层。 下一章将详细讨论由这些层组成的网络。

  • 机器学习模型中的关键要素是训练数据、损失函数、优化算法，还有模型本身。

  • 矢量化使数学表达上更简洁，同时运行的更快。

  • 最小化目标函数和执行极大似然估计等价。

  • 线性回归模型也是一个简单的神经网络
