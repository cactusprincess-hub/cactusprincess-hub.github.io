二、本章核心规则

  • SQL 是关系数据库的标准语言，介于关系代数与关系演算之间，集查询、操纵、定义和控制于一体。
  • SQL 的特点是：综合统一、高度非过程化、面向集合、语法统一且简洁易学。
  • SQL 支持三级模式结构：基本表对应模式，视图对应外模式，存储文件对应内模式。
  • 基本表是独立存在的真实表；视图是从一个或多个基本表导出的虚表，不实际存储数据。
  • DDL 包括 CREATE / DROP / ALTER；DML 包括 SELECT / INSERT / UPDATE / DELETE；DCL 包括 GRANT / REVOKE。
  • 定义表时，主键、外键、唯一性、非空和检查约束是高频考点。
  • 索引能加快查询，但会占空间、增加维护成本；PRIMARY KEY 和 UNIQUE 常会自动建索引。
  • SELECT 的核心顺序是：FROM 确定对象，WHERE 选行，GROUP BY 分组，HAVING 过滤组，ORDER BY 排序。
  • WHERE 负责行筛选，HAVING 负责组筛选；WHERE 不能直接用聚集函数。
  • 视图的更新很复杂，有些视图可更新，有些不可更新；WITH CHECK OPTION 用来限制通过视图修改时不能破坏视图条件。
  • 嵌入式 SQL 需要预编译、主变量、SQLCA 和游标来协调“集合操作”和“过程式处理”的差异。
    经验句：
    SQL 先记四件事：建什么、查什么、改什么、谁能改。
