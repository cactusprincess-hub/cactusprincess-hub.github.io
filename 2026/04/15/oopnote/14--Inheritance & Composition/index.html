二、本章核心规则

  • C++ 的一个重要特性是代码复用，类之间的关系通常通过 composition 和 inheritance 来表达。composition 是 has-a，inheritance 是 is-a。
  • 组合和继承都会让新类里包含子对象，只是来源不同：组合是把成员对象放进去，继承是把基类子对象放进去。
  • 派生类对象创建时，先构造基类子对象，再构造成员子对象，最后构造派生类自己。析构顺序相反。
  • 构造函数初始化列表可以显式调用成员对象或基类构造函数。
  • 如果派生类里重新定义了某个函数名，基类里同名的其他重载版本会被自动隐藏。
  • 构造函数、析构函数、赋值运算符不会自动继承。
  • 继承中的 static 成员函数会被继承，但它们没有 this，只能访问 static 成员，也不能是 virtual。
  • public / protected / private 继承会改变基类成员在派生类中的可见性；派生类成员函数仍可访问基类的 public 和 protected 成员，但对象能不能访问，要看继承方式。
  • 除赋值运算符外，运算符通常会自动继承到派生类。
  • 多重继承可能带来同名成员函数歧义；虚基类可以解决“基类被继承两次”的问题。
  • 派生类对象可以通过指针或引用被当作基类对象使用，这叫向上转型。
    经验句：
    这章就记四件事：谁包含谁、谁先构造、谁会隐藏、谁会歧义。

三、本章常考题型

1. 组合还是继承

考你某个设计是 has-a 还是 is-a。
记住：需要“拥有一个功能对象”时常用组合；需要“完全像基类那样工作”时常用继承。

2. 构造初始化顺序

考你成员对象和基类对象到底谁先构造。
记住：先基类，再成员，最后派生类本体。

3. 名字隐藏

考你派生类改了一个函数名后，基类的重载版本是否还能直接调用。
记住：同名就可能把整组版本藏起来。

4. 访问控制

考你 public / protected / private 继承后，派生类对象和派生类成员函数分别能访问什么。

5. 多继承二义性

考你同名函数从两个基类都继承来时怎么消歧。

6. 虚基类

考你为什么要 virtual 继承，构造函数怎么写，A 只构造一次还是多次。

7. 向上转型

考你派生类对象能否传给基类引用或指针参数。

PDF 用 Derived3 和 Derived4 说明，只要派生类里出现了同名函数，不管你是改返回类型还是改参数列表，基类那组同名函数都可能被隐藏。

11. 选择 composition 还是 inheritance

PDF 给出的判断标准非常实用：

  • 你想把一个已有类的功能“作为数据成员拿来用”，但不想暴露它的接口，选 composition，通过类里的类调用接口
  • 你想让新类拥有和已有类几乎一样的接口，选 inheritance。直接类–接口，这个东西新子类就叫派生类
    经验句：
    想“有一个”就组合，想“就是一个”就继承。

13. 一个直接派生类不能访问基类 private

PDF 强调：基类 private 成员只能被它自己的成员函数和友元访问；直接派生类无论如何继承不能访问 private，但可以访问 public 和 protected。

经验句：
private 是“只给自己用”的。

14. 继承方式改变可见性

PDF 的表格可记成一句话：

  • public 继承：基类 public 仍是 public，protected 仍是 protected
  • protected 继承：基类 public/protected 变成 protected
  • private 继承：基类 public/protected 都变成 private。

经验句：
继承方式像“权限压缩器”，越往后越收紧。

15. 组合与继承在子类访问上的差别

PDF 的 Rectangle 例子说明：如果 Rectangle : public Location，那么 Rectangle 的对象还能直接访问 Location 的 public 成员；如果改成 private Location，那么这些接口就不能再被对象直接使用，需要在 Rectangle 里重新包装。

错误场景：
这里是在类外通过对象 点 方式访问 所以不行 只有pub可以

修正思路：
在子类重新定义 由于这里是类内 所以可以访问私有 相当于自己访问自己

经验句：
private 继承不是“不能用基类”，而是“不能直接把基类接口露出去”。

PDF 说，继承最重要的不只是“新类拿到了父类函数”，而是“新类和基类之间形成了类型关系”。因此，派生类对象可以通过==指针或引用==当成基类对象使用，这叫向上转型。

五、本章重点回忆版

  • 组合：类里放另一个类对象。
  • 继承：新类是旧类的一种。
  • 构造顺序：基类 → 成员对象 → 派生类本体。
  • 初始化列表：用来初始化基类和成员对象。
  • 名字隐藏：派生类重定义同名函数后，基类同名重载可能一起被藏掉。
  • 自动继承不了的：构造函数、析构函数、赋值运算符。
  • static 函数没有 this，不能访问普通成员，也不能虚函数化。
  • public / protected / private 继承会改变对外可见性。
  • 多继承容易歧义，必要时用作用域限定或虚基类。
  • 向上转型：派生类对象可当基类引用/指针用。
