二、本章核心规则

  • 运算符重载本质上还是函数调用，只是写法更像表达式。

  • 不能新造运算符，不能改运算符优先级、结合性、操作数个数，也不能改语法结构。

  • 只用于内置类型的表达式，不能被重载。

  • 运算符函数名写成 operator@。

  • [] 和 -> 必须是成员函数。

  • ++、-- 要分前置和后置，后置版本靠一个“占位用的 int 参数”区分。

  • operator+ 常返回新对象；operator+= 常返回当前对象引用。

  • =、拷贝构造、自动类型转换这三块最容易和代码题连在一起考。

三、本章常考题型

1. 判断成员函数还是友元函数

常考：c1 + 1.5、1.5 + c1 哪个能过。
记住：左操作数是不是当前类对象，是判断关键。

2. 判断前置 ++ / 后置 ++

常考：++a 和 a++ 是否调用同一个函数。
记住：不是同一个，后置有 int 占位参数。

3. [] 和 -> 的写法

常考：是否能写成非成员函数。
记住：不能，必须成员函数。

4. 赋值运算符和拷贝构造

常考：B = A; 和 Location B = A; 分别调用什么。
记住：前者是赋值，后者是拷贝构造。

5. 指针成员导致的浅拷贝

常考：默认拷贝为什么出错。
记住：多个对象可能指向同一块堆内存。

6. 自动类型转换

常考：是构造函数转换，还是 conversion operator。
记住：进来变成我，用构造函数；我出去变成别的类型，用转换运算符。

9. 前置 ++ 和后置 ++

PDF 说明，前置和后置要分开写；后置版本用一个无意义的 int 参数区分。前置是“先改再用”，后置是“先用再改”。

  1. 前缀 ++ /–（先变再用）
    写法：类型 operator++() / 类型 operator–()
    无参数
    逻辑：先自增 / 自减，再返回自身
    返回：推荐类型 &（引用，支持链式）
  2. 后缀 ++ /–（先用再变）
    写法：类型 operator++(int) / 类型 operator–(int)
    必须带 int 占位参数（dummy，编译器自动传 0，你不用管）
    逻辑：先存旧值 → 自增 / 自减 → 返回旧值副本
    返回：类型（值，临时对象，不能返回引用）
  3. 死记规则
    前缀：无参
    后缀：必须有 int 哑参
    这个 int 只用来区分前后缀，没有任何实际用途

13. 指针成员的深拷贝问题

PDF 重点提醒：类里一旦有裸指针成员，默认拷贝可能让多个对象指向同一块内存，导致重复释放。于是必须自己写拷贝构造和赋值运算符，做深拷贝。
只有类里有指针 **，才分浅 / 深拷贝；没有指针，两者完全一样 **

1. 浅拷贝（编译器自动给的）

只复制指针的地址，不复制内存

→ 多个对象共用同一块内存

❌ 问题：析构时重复删内存→程序崩溃；赋值会丢内存（泄漏）

2. 深拷贝（必须手动写）

不复制地址，新开一块独立内存，只复制数据

→ 每个对象各用各的内存

✅ 安全，不崩溃、不泄漏
终极口诀

浅拷贝：共用地址，必崩

深拷贝：各开内存，安全
