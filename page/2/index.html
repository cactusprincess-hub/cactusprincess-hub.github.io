深度学习笔记（五）：线性回归及它的朋友们

一、序言

机器学习模型从本质上来说，是在做一件非常简单的事情：通过数据找到一个函数，让输入可以尽量准确地预测输出。比如说，如果我们有很多房子的面积和对应的房价，我们就希望找到一个函数，当输入面积的时候，这个函数可以输出一个接近真实房价的数值。假设我们只有一个特征（面积），最简单的模型就是线性回归。线性回归假设输入和输出之间是一个线性关系，也就是说：
$y = wx + b$
这里的 (x) 是输入特征，比如房屋面积，(w) 是权重，表示面积对房价的影响程度，而 (b) 是偏置，可以理解为基础价格。这个公式的含义其实非常直观：房价等于面积乘以一个系数，再加上一个基础值。如果我们有多个特征，比如面积、地段、楼层等等，那么公式就会变成：
$y = w_1x_1 + w_2x_2 + … + w_dx_d + b$
如果用矩阵形式写，会更紧凑：$y = Xw + b$
这里的 (X) 是输入数据矩阵，每一行是一条数据，每一列是一个特征；(w) 是权重向量；(b) 是偏置。

这个公式的意思是计算预测值和真实值之间的差，然后把这个差平方，最后取平均。平方的原因是为了让误差始终为正，同时也让大的误差被更强烈地惩罚。在 PyTorch 中我们可以这样写：

为了知道应该怎么修改参数，我们需要计算损失函数对参数的导数，也就是梯度。例如：$\frac{\partial L}{\partial w}$
这个导数告诉我们，当 (w) 变化一点点的时候，损失函数会如何变化。如果导数是正的，说明增加 (w) 会让损失变大，因此我们应该减小 (w)；如果导数是负的，说明增加 (w) 会让损失变小，因此我们应该增加 (w)。换句话说，导数告诉我们最陡的上升方向，而我们为了让损失变小，需要往相反方向走，这就叫做梯度下降。
梯度下降的更新公式是：$w = w - \eta \frac{\partial L}{\partial w}$
这里的 ($\eta$) 是学习率，表示每一步走多远。直观地说，可以把损失函数想象成一座山，而我们的目标是走到山谷的最低点。梯度表示山坡的斜率，而我们每次都会朝着下降最快的方向走一小步。

到这里我们解决的是回归问题，也就是预测一个连续数值。但是在很多任务中，我们并不是要预测一个具体的数，而是要预测类别，比如识别图片中的动物是猫、狗还是鸟。对于这种多分类问题，通常会在线性层后面加一个 softmax 函数。线性层会先计算每个类别的“得分”，例如：$o = Wx + b$
这里的 (o) 是一个向量，每个元素对应一个类别的分数。然后 softmax 会把这些分数转换成概率： $P_i = \frac{e^{o_i}}{\sum_j e^{o_j}}$
这样得到的每个 ($P_i$) 都在 0 到 1 之间，并且所有概率加起来等于 1。为了训练这样的模型，我们通常使用交叉熵损失（cross entropy loss），它会鼓励模型给真实类别分配更高的概率。实际上，softmax 回归可以理解为在线性回归基础上增加了概率归一化和分类损失函数，而更复杂的神经网络模型也只是把线性层堆叠起来，中间加入非线性激活函数，但训练的基本流程仍然是：前向计算得到预测值，计算损失函数，通过反向传播求梯度，再利用优化器更新参数。
从更宏观的角度来看，几乎所有深度学习模型都遵循同样的基本结构：输入数据经过一系列函数变换得到预测结果，然后通过损失函数衡量预测与真实值之间的差距，再利用梯度下降不断调整模型参数，使得损失越来越小。因此，无论是简单的线性回归，还是复杂的深度神经网络，本质上都是在寻找一个函数，使得输入数据能够被映射到正确的输出，而梯度下降和反向传播则是实现这一目标的核心算法。

二、线性回归和逻辑回归

在机器学习中，线性回归（Linear Regression）和逻辑回归（Logistic Regression）其实是同一条思路逐渐发展的结果。理解它们最好的方式不是把它们当成两个完全不同的模型，而是把它们看作同一个基本框架在不同任务下的变化。整个逻辑仍然是：输入数据，通过一个函数得到预测值，然后通过损失函数衡量预测误差，再通过梯度下降不断调整参数，使模型预测越来越准确。

线性回归

线性回归解决的是回归问题，也就是预测一个连续数值。例如房价预测、温度预测、销售额预测等等。线性回归的核心假设是：输入特征和输出之间存在一个线性关系。假设每个数据点有 (d) 个特征，我们用向量 ($x=(x_1,x_2,…,x_d)$) 表示输入，那么模型会假设输出 (y) 可以写成 $y = w_1x_1 + w_2x_2 + … + w_dx_d + b$
其中 ($w_1,w_2,…,w_d$) 是每个特征对应的权重，表示这个特征对预测结果的影响程度，而 (b) 是偏置，可以理解为基础值。如果用向量形式写得更紧凑一些，这个公式可以写成：$y = w^Tx + b$
这里 ($w^Tx$) 表示权重向量和输入向量的点积。在数据集中，如果我们有很多条数据，就可以把所有输入特征写成一个矩阵 (X)，于是整个模型可以写成：
$\hat y = Xw + b$`
这里的 ($\hat y$) 表示模型预测值。线性回归训练的目标是找到一组参数 (w) 和 (b)，使得预测值和真实值尽量接近。为了衡量这种差距，我们通常使用均方误差（MSE）作为损失函数：$L = \frac{1}{n}\sum(\hat y - y)^2$
这个公式表示对每个样本计算预测误差，然后平方，再求平均。平方的作用是避免正负误差相互抵消，同时让较大的误差被更强烈地惩罚。接下来就可以通过梯度下降来优化参数。我们计算损失函数对参数的导数，例如 ($\partial L / \partial w$)，然后按照
$w = w - \eta \nabla L$
这样的规则不断更新参数，其中 ($\eta$) 是学习率。随着训练迭代次数增加，模型会逐渐找到一组参数，使得预测结果与真实值之间的误差尽量小。
然而，线性回归有一个很明显的限制：它的输出是任意实数。例如模型可能输出 -3、5.2、100 等等。这对于预测数值没有问题，但如果我们的任务是分类，比如判断一封邮件是不是垃圾邮件，就会遇到困难。分类问题的输出通常是概率或者类别，而不是任意实数。例如在二分类问题中，我们希望模型输出一个在 0 和 1 之间的概率，表示某个样本属于某个类别的可能性。

逻辑回归

为了解决这个问题，人们在线性回归的基础上增加了一个非线性函数，这就是逻辑回归（Logistic Regression）。逻辑回归的第一步仍然是计算一个线性得分：$z = w^Tx + b$
这一步和线性回归完全一样，模型仍然是在计算输入特征的加权和。但接下来，我们不会直接把这个值作为预测结果，而是把它送入一个叫做 sigmoid函数 的函数中：
$\sigma(z) = \frac{1}{1 + e^{-z}}$
这个函数的作用是把任意实数映射到 0 到 1 之间。无论输入是多大的正数或负数，输出都会落在这个范围内。例如，如果 (z) 很大，sigmoid 的输出会接近 1；如果 (z) 很小，输出会接近 0；如果 (z=0)，输出就是 0.5。因此，逻辑回归的完整模型其实是：$p = \sigma(w^Tx + b)$
这里的 (p) 就可以被解释为某个样本属于正类别的概率。例如在垃圾邮件检测中，(p) 可以表示邮件是垃圾邮件的概率。如果这个概率大于 0.5，我们就预测为垃圾邮件，否则预测为正常邮件。

逻辑回归的训练方式和线性回归也类似，但损失函数会换成更适合概率预测的形式，通常是交叉熵损失（cross entropy loss）。交叉熵的思想是：如果模型给真实类别分配的概率越高，那么损失就越小；如果模型把概率分给错误类别，损失就会变大。对于二分类问题，交叉熵损失可以写成：
$L = -[y \log(p) + (1-y)\log(1-p)]$
这里 (y) 是真实标签（0或1），(p) 是模型预测的概率。如果真实标签是 1，那么损失主要取决于 ($-\log(p)$)，这意味着模型只有在 (p) 接近 1 时损失才会很小。如果真实标签是 0，那么损失主要取决于 ($-\log(1-p)$)，也就是说模型必须给这个类别很小的概率才会得到较小的损失。

训练逻辑回归的过程仍然和线性回归完全一样：先通过模型计算预测概率，然后用损失函数计算误差，再通过反向传播计算梯度，最后利用梯度下降更新参数。随着训练进行，模型会逐渐学会给正确类别分配更高的概率。

从整体来看，逻辑回归其实只是在线性回归基础上的一个小变化。它仍然使用线性函数来计算特征的加权和，只是把输出通过一个 sigmoid 函数压缩到 0 到 1 的区间，并且使用适合概率预测的损失函数来训练模型。因此，从结构上来说，逻辑回归仍然可以看作是一个线性模型，它学习到的决策边界仍然是线性的。例如在二维空间中，逻辑回归学到的分类边界是一条直线；在更高维空间中，这个边界是一个超平面。

理解了线性回归和逻辑回归之后，就可以很自然地理解后续的模型，例如 softmax 回归和神经网络。softmax 回归实际上是逻辑回归在多分类问题上的推广，而深度神经网络则是在这些线性模型之间加入更多的非线性变换，从而让模型能够表示更复杂的函数关系。但无论模型多么复杂，它们训练时依然遵循同样的基本流程：通过前向计算得到预测结果，利用损失函数衡量预测误差，再通过反向传播计算梯度，最后用梯度下降更新参数。

三、softmax regression

先说一个核心事实：
softmax regression 本质是在学“分类边界”。
假设只有两个类别：猫和狗。模型做的事情其实非常简单，就是给两个类别各算一个分数。比如模型看到一张图片以后，算出来两个值：
猫的分数 = 3.2
狗的分数 = 1.1
那我们就说这张图是猫，因为猫的分数更高。
注意这里还没有概率，只有“分数”。

线性方程

这个分数是怎么来的？其实就是一个线性函数：
$猫的分数 =(w_1^Tx + b_1)$
$狗的分数 = (w_2^Tx + b_2)$

其中 (x) 是输入特征，比如图像的像素、或者神经网络前面层输出的向量。
所以模型其实是在做这件事：
输入特征 → 用不同参数算每个类别的分数 → 分数最高的类别就是预测结果。

接下来关键问题来了：什么时候猫和狗的分数一样？
当 $w_1^Tx + b_1 = w_2^Tx + b_2$
整理一下：$(w_1 - w_2)^T x + (b_1 - b_2) = 0$
这就是一个线性方程。
在二维空间它是一条线，在三维空间是一个平面，在高维空间就是一个超平面。
这条线（或平面）就是：分类边界。
边界一边是猫，一边是狗。
所以 softmax regression 真正做的事情是：
通过学习参数 (W) 和 (b)，找到最好的分类边界。
这就是为什么很多机器学习算法本质一样，比如：
logistic regression
softmax regression
SVM
它们其实都在学: 用一个超平面把类别分开。
只不过它们的训练方式不同。

softmax

接下来我们再看 softmax 的作用。
刚刚我们说模型算出来的是分数，比如：
猫 = 3.2
狗 = 1.1
但是机器学习很多时候希望输出的是概率，比如：
P(猫 | x) = 0.88
P(狗 | x) = 0.12
概率必须满足两件事：
第一，不能是负数
第二，加起来必须等于1

而线性函数算出来的分数完全不满足这些条件。可能是负数，也可能非常大，而且总和也不等于1。
所以我们需要一个函数，把“任意分数”变成“概率分布”。 这个函数就是 softmax。

softmax 做的事情其实很简单：先把所有分数做指数运算，然后再除以总和。
比如原始分数：
2
1
0
做指数以后变成：
7.39
2.72
1
再除以总和 11.11：
0.66
0.24
0.09
这样我们就得到了一个概率分布。
这里指数函数有一个很重要的性质：
大的分数会被放大，小的分数会被压缩。
比如：
原始分数差距 2 和 1
指数以后差距变成 7.39 和 2.72
所以 softmax 会让模型更“自信”。
分数差距越大，概率差距也越大。
但是你要注意一个非常关键的事实：softmax 不改变哪个类别最大。
因为指数函数是单调的。 最大分数经过指数以后还是最大。
所以在很多实际系统里，预测的时候甚至不计算 softmax，直接选最大分数。
softmax真正的作用不是帮助预测，而是帮助训练概率模型。
接下来是 cross entropy。
我们现在已经有了概率，比如：
模型预测：
猫 0.66
狗 0.24
鸡 0.10
真实标签假设是猫。

交叉熵

那问题来了：我们怎么判断模型预测得好不好？
这时候就需要一个“误差函数”，也叫 loss function。
很多初学者会想到用均方误差（MSE），但概率模型里更合理的是 交叉熵。
交叉熵其实来自信息论，它的直觉非常简单：
如果真实类别概率很大，loss 就小；如果真实类别概率很小，loss 就大。
公式是: $L = -\sum y_i \log(\hat y_i)$
但在分类问题里其实更简单，因为真实标签是 one-hot。
比如真实标签：
猫 = 1
狗 = 0
鸡 = 0
那 loss 就变成: $L = -\log(P(猫))$
所以训练目标就是: 让真实类别的概率尽可能大。

举几个直觉例子。
如果模型预测：猫 0.9
loss：(-$\log 0.9$ ≈ 0.1)非常小，说明模型很好。
如果预测：猫 0.5
loss：0.69更大，说明模型不太确定。
如果预测：
猫 0.01
loss：4.6. 非常大，因为模型非常自信但却错得离谱。

所以交叉熵会严重惩罚自信但错误的预测。 这让模型更稳定。
还有一个非常重要但教材很少强调的数学性质：softmax + cross entropy 的梯度非常简单。
结果是 预测概率 − 真实概率
也就是 : $\hat y - y$ 。这和线性回归的误差形式非常像，所以梯度下降非常稳定。

总结

这也是为什么深度学习几乎所有分类模型都用. softmax + cross entropy
比如：
CNN 分类
BERT 分类
GPT 预测下一个词

最后一层几乎都是这个结构。
现在我们把整章逻辑串起来总结一下（这是需要真正记住的部分）。
整个 softmax regression 模型其实只有三步。
第一步：线性打分
输入特征 (x)，用线性模型计算每个类别的分数：$o = Wx + b$
每个类别都会有一个分数。
第二步：softmax
把分数变成概率分布: P(y|x)
这样所有概率加起来等于1。
第三步：cross entropy
用交叉熵衡量预测概率和真实标签的差距。

训练目标就是：
让真实类别的概率尽量接近1。最后用梯度下降更新参数 (W) 和 (b)。
从几何角度看，模型其实是在做一件更直观的事情：学习一组超平面，把不同类别的数据分开。
每两个类别之间都会形成一个分类边界。
所以 softmax regression 可以理解为：
用线性函数给每个类别打分 → 用 softmax 变成概率 → 用交叉熵训练参数 → 学到最好的分类边界。

📗 第二部分：核心知识库（术语解构）

为了让你“知其然更知其所以然”，以后面试或跟同学聊技术也能信手拈来。

1. Homebrew：Mac 的“万能管家”

  • 定义：它是 macOS 上的 包管理器 (Package Manager)。

  • 直白点说：它是给程序员用的“App Store”。在 Mac 上装开发工具，不用去官网下安装包，直接 brew install 搞定，且方便后续统一升级。

2. Node.js：博客的“发动机”

  • 定义：一个基于 Chrome V8 引擎的 JavaScript 运行时 (Runtime)。

  • 为什么需要它：Hexo 是用 JavaScript 编写的。Node.js 就像是运行 Hexo 这台机器的电力系统，没有它，Hexo 无法在你的 Mac 上运行。

3. Hexo：静态网站“代工厂”

  • 定义：一个 静态网站生成器 (Static Site Generator)。

  • 工作原理：

    • 输入：你写的 Markdown (源文件)。

    • 模具：Icarus 主题 (HTML/CSS 模板)。

    • 输出：纯网页代码 (HTML/JS/CSS)。

  • 优点：生成的是纯静态页面，不涉及后端数据库，所以访问极快且完全免费。

4. Git & GitHub：仓库与店面

  • Git：版本控制系统。记录你博客每一次的改动，就像游戏的“存档”。

  • GitHub：全球最大的代码托管平台。

  • GitHub Pages：GitHub 提供的静态网页托管服务。它分配给你一个 xxx.github.io 的域名，并免费帮你运行刚才生成的那些网页。

5. SSH (Secure Shell)：加密握手

  • 定义：一种网络协议，用于计算机之间的加密登录。

  • 为什么要用：

    • HTTPS 方式（用户名+Token）：像每次进门都要掏身份证、输密码，不仅累且容易超时报错。

    • SSH 方式：像“面部识别”。你把公钥给了 GitHub，你每次推送代码，它们会自动比对你的私钥，确认是你本人后秒放行。

📙 第三部分：避坑 & 小贴士

  1. 缓存是万恶之源：如果你改了配置却没生效，永远记得先 hexo clean。

  2. YAML 语法：.yml 文件对缩进极其敏感。冒号后面必须有一个空格！

    • 错误：title:我的博客

    • 正确：title: 我的博客

  3. 图片管理：如果你想在文章里插图，建议把图片放在 source/img/ 下，然后在 Markdown 里引用。

  4. 备份源码：GitHub 上的那个仓库是“成品”。你的 myblog 文件夹本身才是真正的宝贝。记得定期拷贝到移动硬盘，或者再建一个 GitHub Private 仓库，把整个文件夹（除了 node_modules）存上去。
